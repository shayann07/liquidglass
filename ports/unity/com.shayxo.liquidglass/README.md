# LiquidGlass for Unity

Liquid Glass for Unity, measured against iOS: the liquidglass production material as a shader for the
Built-in pipeline (`LiquidGlass/Surface`) and URP (`LiquidGlass/Surface (URP)`), with a `GlassSurface`
component for quads and UI. iOS is not a target.

The guide, what is and is not verified, and the checks:
<https://github.com/shayann07/liquidglass/tree/main/ports/unity>.

Apache-2.0.
